# 手机与正式服务验收

候选版本：Android 1.4.0，versionCode 21。使用原发布证书。安装包和完整校验值见 `release-audit.json`。

本轮自动验收使用专用 API 36 模拟器和测试数据；以下项目需要在实际手机或正式服务上检查，尚未标记通过。

| 范围 | 操作 | 通过条件 |
| --- | --- | --- |
| 实际历史数据 | 从手机现有 1.3.13 覆盖安装 | 配对、记录、草稿、附件、收藏及待提交内容保留；核对迁移报告与原件 |
| 系统分享 | 文件管理器、WPS、录音应用分别分享文字和多文件 | 混合内容齐全，取消选择的附件不提交；存为记录和 Agent 路径各自保留内容 |
| 相机与扫码 | 首次拒绝权限、重新授权；扫码、相册识别及手动输入 | 状态准确，拒绝后可继续使用其他入口 |
| 录音 | 暂停、恢复、试听；切后台、锁屏及结束进程后重开 | 录音在后台暂停，已完成片段可恢复，不丢原件 |
| 系统预览 | 手机实际 PDF、DOCX、音频、图片和记录视频 | 阅读或播放正常；不支持的格式仍可保存和外部打开 |
| 系统安装器 | 从正式更新清单下载后覆盖安装 | 哈希与证书校验通过，安装来源权限返回后可以继续；数据不清空 |
| 跨端同步 | 手机离线编辑、另一端更新、再联网 | 本机和远端版本分别可见；确认前不覆盖，确认后沿用正确版本 |
| 加工与审核 | 真实记录加工、审核归档、返回原记录 | 原文与产物分别保留；审核版本变化时重新确认 |
| Codex 实测 | 分享关联真实电脑和项目，后台完成后回看报告 | 安装、加载与调用证据来自实际 Agent；报告和原资料、原记录可双向返回 |
| 可访问性 | TalkBack、手机字体缩放、分屏及输入法 | 控件名称与焦点顺序清楚，触控和提交不被键盘遮挡 |
| 性能 | 手机实际大资料库与长文连续浏览 | 无明显卡顿、持续内存增长或正文位置跳动；另行记录帧耗时 |

模拟器的报告跳转使用专用 API 夹具，验证原生页面关系；没有把夹具中的报告当作新发起的真实模型实测。覆盖升级迁移样本为一条记录、一份 24 字节原件、一个服务器收藏及既有原生草稿和队列。

本轮交付为本机候选包，正式主站下载和升级清单尚未更新。
