# 资料库卡片与无限画布

用途：在长期资料库中浏览、整理卡片，点开后继续使用原有正文、分析、原文与附件阅读器，保留列表视图。

视觉：延续积木的研究资料工作台。浅色使用现有白色面板、灰蓝画布和深灰正文；深色沿用现有 #0f1114 / #161a1f / #e6e8eb。状态色复用绿色、琥珀色。遵循应用现有字体变量（Arial/PingFang SC/Segoe UI）与 Lucide 图标；这是既有品牌约束，不引入新字体、联网资源或额外说明小字。

布局：资料库首页默认全宽画布，卡片四列起排，可自由移动和缩放；筛选与视图切换保留在顶部。列表模式保留原分栏布局。画布打开资料后全宽阅读，返回画布保留视角和位置。

实现：复用 packages/ui-react 的 MaterialCanvas，不复制画布引擎。卡片提供已有右键命令，沿用搜索、类型、状态、标签、收藏及分页接口；分页显示已加载与总数，可继续加载。仅呈现真实条目，不推断资料关系。卡片布局与视图偏好按资料空间身份保存在本机，账户切换不串用；无数据库迁移，不修改正文、附件或归档元数据。

验收：浏览器验证分页、筛选、阅读返回、列表切换、收藏、快捷操作、拖动/缩放持久化和账户隔离；正式签名客户端验证既有资料、原文/附件、积木回归、旧记录文稿与升级数据保留。真实手机验收不在范围内。
