# 积木计划模式 · 0.2.40

桌面和 Web 新建积木改为从一句话开始。Agent 通过逐题讨论确认用途和范围，再组织多个目标、部件、验收条件、依赖与资料安排。支持自然语言调整和折叠的结构精修，刷新后恢复未提交输入及已保存讨论。

确认前只保存计划；确认按版本与请求编号去重，不重复创建积木。新积木自动匹配已有资料，外部持续采集需要主动开启，材料满足条件后保留原自动成果交接。旧积木缺省继续原有采集行为。

计划使用现有 AI 助手公开执行接口；新任务通过独立 Worker 协议能力派发，旧节点不领取规划任务。计划结果校验目标结构及资料安排，已失效轮次不覆盖新讨论。关闭插件保留计划，规划记录纳入发布保全快照。

本次保持原资料、文稿、模型配置、授权、应用标识与更新源。真实手机验收暂缓；现有手机快速加入协议不变。部署、本机签名更新及验收回执保留本地，不上传数据库或凭据。
