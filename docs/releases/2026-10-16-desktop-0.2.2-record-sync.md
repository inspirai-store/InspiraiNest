# 桌面客户端 0.2.2：记录同步兼容与冲突处理

Windows x64、macOS Apple Silicon 和 Intel 使用同一源码提交 `460842edb4f1964ba652415f6852cf9baecc8be6`。Windows 沿用 NSIS；Mac 使用 Developer ID 签名、公证的 ZIP/DMG。应用标识、账号授权和资料目录保持原状。

## 修复内容

- 服务端校验、保存并返回正文、完整排版文档和附件引用；旧客户端不能静默删除已有排版。
- 保留 `baseVersion` 条件写入和固定请求的幂等重试。只把已核实的版本变化显示为内容冲突，分别处理协议不兼容、附件问题、请求编号复用、断网和服务不可用。
- 持久化编辑基线，整体比较正文、排版和附件。相同内容直接确认，单端变化安全同步，双方变化交给用户比较。
- 比较界面提供实际排版预览、修改时间、版本、附件和四种处理方式。确认前再次核对云端版本，任何替换前保存本机恢复副本；合并编辑保留原记录 ID。
- 对旧服务端缺失排版的成功回执，先重放原请求，再核对最新云端版本和内容；确认没有后续不同修改后，持久化新的修复请求补回排版。每次同步最多两次记录写入，避免无限重发。

协议、错误码、恢复副本和旧回执修复边界见 [记录同步说明](../../collector/docs/RECORD_SYNC.md)。恢复副本已保存到本机，尚未提供独立的历史浏览界面。
