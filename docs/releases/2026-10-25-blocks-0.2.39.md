# 积木整合 · 0.2.39

本次将长期资料积累、多个目标与部件、语义证据匹配、成熟度评价及成果交接合入公开主线。

- 积木属于可选插件，状态由资料空间持有；停用保留目标、材料和历史。已有资料空间默认关闭。
- 来源按版本匹配。支持证据必须引用输入正文；不完整资料保留为线索。文章交接进入待审阅流程，产品可导出冻结材料包。
- 兼容目前使用的独立采集窗口、采集证据和恢复、分屏写作、大纲工作流、局部格式及加密模型配置。相关源码移入现有 apps/packages/plugins 边界，不迁移用户资料或凭据。
- 服务复用现有 MySQL 记录表和对象存储，不改数据库结构；发布快照同时保护新增的 block/block-handoff 记录。
- 客户端继续使用原应用标识、LibraryWorker 路径、资料空间作用域及钥匙串命名。打包按架构包含 CLI，保留浏览器扩展原路径兼容入口。

验证包含构建、类型与插件边界、原有回归、兼容能力回归及隔离 MySQL。真实手机验收按本次要求暂缓。本机安装、生产部署、数据保全的具体回执保留在本地验收目录，不公开用户文本、凭据或完整数据库备份。
