# 写作问答速度与真实进度：0.2.6

桌面 0.2.6；Android 1.3.12 / versionCode 19；iOS 1.0.6 / build 11 继续待签名。服务和正式客户端下载已上线；四个桌面客户端与两台连接的 Android 已原位更新。

## 行为

- 问答提示直接提供完整冻结输入与所需规则，内嵌文字无需重复扫描和读取。AI 返回讨论结果，由 Worker 校验并原子保存；指定附件仍完整下载、校验并供 Agent 读取。
- 问答使用任务级低推理配置，不更改用户全局配置、显式 Agent 自定义参数或正文任务。方向、变化、提纲和问题缩短说明，后续保留历史备选而不每轮重写。
- 页面以实际事件显示材料准备、问题组织、校验、保存，包含用时、执行电脑、真实工具完成次数及上次活动时间。后台存服务端时间戳，不生成进度百分比。问答执行中每 1.5 秒刷新。
- AI 生成的界面文字与协议记录分离，已有会话的内部文件名、字段和校验说明也不再直接展示；用户原话、材料、历史和导出保持完整。
- 新 Worker 同时支持冻结 v1、0.2.5 v2 和本版 v2，按版本与哈希匹配；旧任务不改快照。仅讨论不会创建稿件，正文仍要求明确开始。
