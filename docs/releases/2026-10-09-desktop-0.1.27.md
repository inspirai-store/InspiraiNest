# 桌面客户端 0.1.27 同批发布

发布日期：2026-10-09（Asia/Shanghai）。Windows x64、Mac Apple Silicon 和 Mac Intel 使用公开仓库同一提交、同一桌面版本发布。

## 功能

- 采集记录和系统问题提供一键复制，包含中文说明、北京时间与诊断信息，并保持凭据隐藏。
- 技能市场安装使用 `~/.agent/skills`（单数）作为唯一可更新源，各 Agent 原生目录通过链接读取；Windows 使用 junction，Mac 使用目录软链接。安装和同组更新保留备份，支持失败恢复与回滚。
- 现有个人技能没有批量迁移；确认安装或更新预览后才整理对应技能。任务固定快照继续独立保留。
