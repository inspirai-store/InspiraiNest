# Windows 0.1.25：统一客户端身份

一台电脑对应一个客户端身份。资料管理和后台采集作为同一客户端的能力，设备页统一名称、设备 ID、当前设备标记和撤销入口。

旧桌面登录凭据在主进程中提交双凭据证明，核对同服务域完整硬件身份，迁入原工作节点的身份。原节点 ID、名称、任务、心跳及版本记录保留；旧凭据仅作为内部兼容映射，撤销客户端时一并失效。旧主配置未保存安装 ID 时保留服务端原有安装绑定，仍必须验证两份有效凭据和完整硬件身份；显式不匹配的安装 ID 会被拒绝。
