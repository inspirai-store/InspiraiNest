# 版本更新：线稿与交互

基线：实际安装 0.2.30；保留分屏创作、紧凑大纲、执行记录与原数据。

## 设计规范
目的：判断版本来源、选择正式/Beta、查看真实下载与安装状态。
风格：沿用灵藏实用工具界面。布局参照用户截图的三行区域，左侧内容、右侧操作。
色板：现有 --panel #ffffff / #161a1f，--fg #24313d / #e6e8eb，--line #d6dee6 / #2a3038，--accent #111111 / #e6e8eb，错误色 #b83e41 / #f0645f。
字体：沿用 PingFang SC、Segoe UI 回退；现有产品字体约束覆盖设计 Skill 的默认字体建议。
图标：现有 Lucide。无额外提示小字，状态和错误是业务内容。

## 状态与动作
| 状态 | 内容 | 动作 |
|---|---|---|
| idle | 尚未检查 | 检查更新、日志、切换通道 |
| checking | 正在检查 | 禁止重复检查与切换 |
| current | 已是最新版本；若发布源落后则显示已安装版本更高 | 检查更新、日志、切换 |
| empty | 该通道暂无发布 | 检查更新、切换 |
| available | 新版本、日期、中文要点 | 下载、切换；更多中选择本次完整包 |
| downloading | 真实方式和传输进度 | 禁止安装与切换 |
| downloaded | 已完成校验 | 安装并重启；切换需确认放弃待装选择 |
| waiting_save | 正在保存编辑内容 | 保存失败恢复 downloaded，不安装 |
| waiting_worker | 等待当前任务完成 | 不抢焦点、不强杀 |
| installing | 正在安装 | 禁止重复操作 |
| error | 实际分类错误 | 重试、日志、切换 |

更新日志：1240/900 为右侧区域，740 为单区并保留选择；含随包版本说明和同通道历史。
更新记录：独立保存在本机，不进入记录或资料列表。
启动后 15 秒与每 6 小时静默检查；下载与安装由明确点击触发。
下载方法以实际更新器事件为准，缺少匹配缓存或 blockmap 时完整下载；差异失败回退完整包。
Beta 含正式版；切回正式版禁止降级；未发布的本机版本不伪装为线上最新版。
CodeBuddy 不再新派发、探测或推荐安装；历史可读。旧固定任务需明确改用 Codex，保留 taskId 并增加 attempt。
