# 能力与执行诊断：线稿及交互约定

基线：已验收桌面 0.2.23。顺序：本文线稿 → Pencil → 实现 → 同内容、同窗口实际验收。

## 节点与能力

```text
┌ 节点与能力 ───────────────────────────────────────┐
│ 本机 Mac                                  在线   │
│ 本机执行                 [检测能力] [执行记录] […] │
├───────────────────────────────────────────────────┤
│ 采集                                              │
│ 网页正文与配图    可执行        已验证       [查看] │
│ 音视频分析        待配置        未实测       [配置] │
│ 外部浏览器        待连接        已验证       [连接] │
│ 写作                                              │
│ 资料写作          可执行        未实测       [查看] │
│ 选区改写          可执行        已验证       [查看] │
├───────────────────────────────────────────────────┤
│ 家中 Windows                              离线   │
│ 网页采集 已验证 / 等待节点                 [查看] │
└───────────────────────────────────────────────────┘
```

当前状态与验证记录分列，离线不抹掉历史验证。忙碌显示排队；未启用显示未启用。手机/Web 显示执行节点，浏览器显示配对和当前页连接状态。检测只更新证据，不自动安装、改权限或重启；受控权限样例使用独立目录和本次执行权限，不操作真实来源。

## 任务执行记录

```text
┌ Medium 文章采集 ───────────────────────── 待授权 ┐
│ [结果] [执行记录]                              │
├────────────────────┬────────────────────────────┤
│ 执行历史           │ 本机 Mac / CodeBuddy        │
│ 第二次 本机 Mac ●  │ 步骤：提取正文              │
│ 第一次 Windows     │ 原因：采集命令被拒绝        │
│ 派发评估           │ AGENT_PERMISSION            │
│                    │ 已保留：快照、正文片段      │
│                    │ [查看证据] [处理权限]       │
│                    │ [继续原任务]                │
└────────────────────┴────────────────────────────┘
```

选择执行次数只读切换；不新建、不重试任务。继续原任务复用 taskId、固定工具和已有成果；新执行产生新 attemptId，关联上一次。接管/交还追加事件，正在手动操作时禁止 Agent 操作。转移必须保留旧执行记录，浏览器绑定任务不能假装在另一节点续用本机会话。

## 证据侧栏

```text
┌ 执行证据 ──────────────────────────────────────┐
│ 已确认 / 工具返回                              │
│ 本机 Mac · 第二次执行 · 时间                    │
│ 权限拒绝：指定采集命令                         │
│ 文件：agent-output / 行 12                      │
│ 脱敏片段……                                     │
│ [上一事件] [下一事件] [复制定位]                │
└────────────────────────────────────────────────┘
```

仅展示允许同步的证据字段和片段。事实、程序校验、Agent 上报与分析推断明确区分。无证据显示待确认；本机离线未同步、日志截断、旧历史缺口分别表达。展开证据不授权重试、安装或页面操作。

## 状态与操作

| 状态 | 主要操作 | 行为 |
|---|---|---|
| 待配置 | 配置 | 定位具体依赖/版本，不自动更改 |
| 待授权 | 处理权限 | 打开已有工具配置入口，系统授权由用户完成 |
| 待连接 | 连接页面 | 用户明确选择页面，保留任务来源 |
| 等待节点 | 查看节点 | 展示启动/在线状态，不抢写作焦点 |
| 手动接管 | 继续采集 | 交还页面，沿用原任务 |
| 内容缺失 | 查看缺口/继续补齐 | 保留部分结果与旧版本 |
| 已恢复 | 查看历史 | 当前问题解除，旧证据仍可读 |
| 正常等待 | 继续写作/查看结果 | 不标系统故障 |
| 未同步/证据缺口 | 刷新 | 明确现有范围，不编造原因 |

## 适配和视觉约束

1240：历史与执行详情并排、证据侧栏；900：证据覆盖式侧栏；740：列表、详情、证据单区切换，保留选择和滚动。沿用现有浅深主题、字体、边框与控件；不新建视觉体系，不加解释性小字。长标题换行、路径可断行、操作区自适应，弹层正文滚动、页脚保持可见。

Pencil 需包含三张核心画板、浅深主题与 1240/900/740 适配，以及权限拒绝、离线、证据未同步、历史不完整、已恢复状态。实际数据示例为合成样例，不代表生产设备当前状态。
