# 灵藏页面连接

这是本地桌面版配套的 Manifest V3 扩展源文件。当前以“加载已解压扩展”使用，尚未发布到 Chrome Web Store 或 Edge Add-ons。

1. 在 Chrome 的 `chrome://extensions`（Edge 为 `edge://extensions`）开启开发者模式，加载此目录。
2. 灵藏 → 采集 → 连接外部浏览器 → 浏览器扩展 → 复制连接码。连接码两分钟有效且只可使用一次。
3. 回到要采集的原网页，打开“灵藏页面连接”扩展，粘贴连接码并点击“连接当前页面”。
4. 回到灵藏，选择出现的页面，点击“连接页面”。网页保持原浏览器的 profile 和登录状态。
5. 登录、输入、表单及不支持的页面交互使用“接管页面”与“打开浏览器”；完成后“继续采集”。扩展的“断开连接”立即撤销这次连接。

连接只在本机 127.0.0.1 上传输，使用随机的一次性配对 token 和独立会话 token。扩展不会枚举历史记录或读取 Cookie。`debugger` 权限用于读取选中标签的结构、截图和执行正文展开动作；浏览器会显示调试状态。只连接你在扩展中明确选中的标签。

当前识别主文档中可见的正文展开按钮、summary、aria-expanded 控件及同文档链接。跨域 iframe、Canvas 内控件、Shadow DOM 深层控件、表单和普通任意链接不在自动点击范围，使用人工接管。页面有变化时旧观察编号失效，需要重新观察。
