## 重复构建

在本目录运行。`Config/Local.xcconfig` 已生成本机模拟器/未签名配置，
Bundle ID 为 `store.inspirai.library`，App Group 为 `group.store.inspirai.library`。
这些值不代表已在 Apple 开发者账户注册。

```sh
xcodegen generate --spec project.yml

xcodebuild -project PersonalLibrary.xcodeproj -scheme PersonalLibrary \
  -configuration Release -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData -jobs 2 ARCHS=arm64 build

xcodebuild -project PersonalLibrary.xcodeproj -scheme PersonalLibrary \
  -configuration Debug \
  -destination 'platform=iOS Simulator,id=081D27BA-C187-4641-B27F-0B4AD3FAC185' \
  -derivedDataPath DerivedData -parallel-testing-enabled NO test

xcodebuild -project PersonalLibrary.xcodeproj -scheme PersonalLibrary \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath build/DerivedData-device \
  -archivePath build/PersonalLibrary-unsigned.xcarchive \
  -jobs 2 CODE_SIGNING_ALLOWED=NO archive
```
