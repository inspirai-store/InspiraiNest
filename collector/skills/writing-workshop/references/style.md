# 从指定范文提炼行文规则

只使用 sources 中 role=exemplar 的资料；必须完整阅读，标清原段落、页码或时间位置。可提炼：问题如何引入、论点如何推进、案例怎样使用、句段节奏、语气与视角、术语解释、引用嵌入、结尾收束及图文关系。
资料库条目的 files[].role 区分发表正文、原文、摘要与加工记录。范文风格从用户选定文章的 publication 或原文正文提炼，不能误把资料库的整理摘要、核验说明或加工记录当成范文。原文缺失时请用户指定全文。

候选规则包含 id、instruction（可执行）、sourceId（对应范文）、example（具体原文定位与例证）。附 sample，用当前材料试写一段，不能创造当前材料不存在的事实。避免只用“克制、自然、有深度”概括风格。
风格档案的 appliesTo 写明适用的文章类型和条件；尚不明确时用问题确认。用户可以只采用部分规则，并通过继续讨论修改规则和试写，再确认版本。

用户选择保留的规则并确认后，应用创建不可变风格版本。多个范文相互冲突时，解释冲突并让用户选择适用文章类型；不能暗中取平均风格。已经确认的规则不随一次修改自动升级。后续蒸馏需要用户明确指定新样本、确认候选规则并生成新版本。

语言编辑检查真实读者价值，不依赖 AI 检测器。具体观察应有材料；过渡应推动论证；重要边界应放在相应判断旁；结尾只在必要时收束，不重复全文。不把任何词汇一律禁用，不强制固定段长或万能结构。
