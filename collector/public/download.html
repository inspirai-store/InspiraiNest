安装后，连接自己的资料库

  1. Windows 打开 EXE 完成安装；macOS 打开 DMG，将应用拖入“应用程序”。
  2. 在已登录的官网或客户端「授权设备」生成配对码，再在工作台完成配对。
  3. 阅读与管理任务可直接使用；让本机执行采集前，准备好 Codex CLI 或 CodeBuddy CLI。

在「设置」调整主题、关闭行为和开机自启动。采集已启动时关闭工作台，Worker 会继续后台处理。

让收藏的资料，

03 / 确认连接

在浏览器确认，只授予读取权限。

授权后，AI 即可按需搜索、阅读和引用。授权有效期 30 天，可在“授权设备”中随时撤销。

lingnest auth login

默认连接官网资料库；其他部署可通过 --server 指定 HTTPS 地址。登录与后续查询须使用同一系统账户。

CLI 预览版：官网已支持浏览器确认的只读授权，首次连接需核对确认码。Windows x64 已实测，macOS / Linux 尚待原生运行验收；Linux 需要可用的 Secret Service。

第一次使用

装好，再连接
自己的资料库。

Android 8.0 及以上 · 手机需能访问资料库服务

  1. 1

    下载安装包

    点击上方按钮下载 APK，在下载列表中打开。若系统询问，允许当前浏览器安装此应用。

  2. 2

    取得设备配对码

    在已有客户端的「授权设备」中生成一次性配对码；首次连接也可使用管理员密钥。

  3. 3

    打开 App，完成配对

    扫描二维码或从相册识别，也可手动填写服务地址和配对码，确认后点击「配对并登录」。
