# Markdown 格式化边缘案例

本文档记录 WeChat 文章转换 pipeline 中遇到的特殊 HTML 结构和对应的修复方案，供后续维护参考。

## 1. 列表断裂：`<li>` 内嵌 `<p>`

**现象**：Markdown 输出中出现独立的 `-` 独占一行，隔开空行后才是列表内容。

```
-

❌ 某些内容
```

**根因**：微信文章 HTML 中列表结构为：

```html
<ul>
<li>
  <p>❌ 某些内容</p>
</li>
</ul>
```

解析器处理 `<li>` 时写入 `- `，然后 `<p>` 触发 `add_newlines(2)`，在 `handle_data` 收到内容之前先输出了空行，导致 `-` 和内容被隔开。

**修复**：`_fix_orphan_list_markers()` 在 post-processing 阶段检测：
1. 扫描独立成行的 `-` 或 `1.` 标记
2. 跳过中间所有空行
3. 找到下一个非空内容合并为同一行

### 1.1 防误合

跳过空行时检查目标行是否也是列表标记开头，避免将两行列表合并为一行：

```
-

item A

-

item B
```

→ 正确输出 `- item A\n- item B`，而不是合并到同一行。

## 2. 引用断裂：`<blockquote>` 内嵌 `<p>`

**现象**：`>` 独占一行，内容在下一行，渲染后引用失效。

```
>

引用内容
```

**根因**：与列表断裂相同——`<blockquote>` 写入 `> `，内嵌的 `<p>` 触发空行。

**修复**：`_fix_orphan_blockquotes()` 检测独立成行的 `>`，跳过空行，将下一段非空内容合并为 `> 内容`。

### 2.1 防误合

跳过以 `#`、`````、`>`、`---`、`|`、`![` 开头的行，避免破坏标题/代码块/嵌套引用/表格/图片。

## 3. 表格缺分隔行

**现象**：表格无分隔行，在 Obsidian / GitHub 等 GFM 渲染器中一整段显示为粘连文字而不渲染为表格。

**根因**：HTML 表格 `<table>` → `<tr>` → `<th>` / `<td>` 处理后只有数据行：

```
| 模式 | 正则 |
| **a** | b |
| **c** | d |
```

缺少 GFM 要求的 `|---|---|` 分隔行。

**修复**：`_fix_table_separators()` 扫描连续的 `|...|` 行，在第一个数据行后自动插入分隔行。列数随 header 动态计算。

### 3.1 已存在分隔行的表

如果 HTML 表格已带 `|:---|---:|` 等分隔行，`is_sep_row()` 通过正则 `^:?-{3,}:?$` 识别，不再重复添加。

### 3.2 多表连续

连续两个不同列数的表能各自正确处理：

```
| A | B |
| a | b |

| X | Y | Z |
| x | y | z |
```

→ 分别插入 `|---|---|` 和 `|---|---|---|`。

## 4. 代码块统一 `text` 标签

**现象**：所有代码块显示为 ` ```text `，无法区分 Python / Bash / YAML 等不同语言。

**根因**：`HTMLToMarkdownParser` 遇到 `<pre>` 时硬编码 ` ```text\n `。

**修复**：改为 ` ```\n `（空语言标签），配合 `format_markdown` 删除强制替换逻辑。用户可在 Obsidian 中按内容手动添加高亮语言，如 ` ```python `、` ```bash `。

### 4.1 微信文章的局限性

微信文章的代码块在 HTML 中不带 `language-*` class，因此 pipeline 无法自动检测语言。本修复不做猜测式标记，以避免错误的语法高亮。

## 5. 电话号/日期误识别为表格

**现象**：HTML 中包含 `<td>13800138000</td>` 等纯数字内容，可能被误认为是表。微信文章不常用此结构，但非微信 HTML 转 markdown 时需注意。

**当前处理**：`is_data_row()` 通过 `|` 在单元格间的分布来判断，不会将纯数字误识别为表格行。

## 6. 其他噪声处理

| 噪声模式 | 示例 | 处理方式 |
|---|---|---|
| 微信水印 | "预览时标签不可点" | `WECHAT_NOISE_PATTERNS` 正则匹配移除 |
| 滑动提示 | "继续滑动看下一个" | 同上 |
| 扫一扫 | "微信扫一扫关注该公众号" | 同上 |
| 社交噪音 | "喜欢此内容的人还喜欢" | `_is_wechat_metadata_noise()` 移除 |
| 阅读原文 | "轻触阅读原文" | `WECHAT_NOISE_PATTERNS` 正则匹配 |
| 来源引用 | "以下文章来源于..." | 同上 |
| 作者行 | "作者 \| xxx" | 同上（特殊引用格式） |
