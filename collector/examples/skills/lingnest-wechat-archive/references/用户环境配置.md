# 项目环境配置

Use this file only for project-specific defaults. Keep it generic before publishing the skill to GitHub, and do not store API keys, tokens, private usernames, or machine-specific paths.

## Recommended Defaults

| 用途 | 默认值 |
|---|---|
| 输出根目录 | `./articles` |
| 是否保存 HTML | 按用户要求添加 `--save-html` |
| Python 命令 | 优先使用当前环境可用的 `python` 或 `python3` |

## Default Save Command

```bash
python scripts/wechat_article_pipeline.py "<url>" --output-dir "./articles"
```

When the user asks to preserve the cleaned HTML:

```bash
python scripts/wechat_article_pipeline.py "<url>" --output-dir "./articles" --save-html
```

## Markdown Quality Standard

The output should be valid GitHub-flavored Markdown, not merely visually close.

| Area | Requirement |
|---|---|
| Tables | Must include a separator row such as `|---|---|` |
| Lists | The marker and text must be on the same line |
| Code fences | Keep empty language tags unless the source clearly identifies the language |
| Blockquotes | The `>` marker and quote text must be on the same line |
| Images | Local image links must point to files in the generated article folder |

If output violates these rules, fix the generated Markdown or update `scripts/wechat_article_pipeline.py` and document the case in `references/formatting-edge-cases.md`.
