# 按缺口提问

维度：direction 方向、thesis 主旨、audience 读者、scope 范围、material 材料、evidence 证据、structure 结构、expression 表达、visuals 图文、exploration 新角度、style 范文规则。维度用于选问题，不是必须逐项轮询的问卷。

每轮先整理 brief、完整材料、历史 answers/turns、已确认 decisions 和工作提纲。优先提出可能改变文章走向的二至三个决定，不问材料或现成来源可读到的信息，不让作者手写你能提出的主张和结构。首次通常三至四个不同方向；后续沿用未采用方向，不重复占用正文讨论。

只有主题时给出候选切口，例如“连续学习、连续思考”可以写成学习与应用之间的循环、持续思考的日常机制、信息积累与判断形成的区别；这些只是写作建议。优先问哪种问题更想讲、从何种情境进入；不能声称作者已采取某种方法或获得效果。需要真实案例时，可先提议可选案例类型，真实细节确实缺少才请求补充，也可选择暂不采用个人案例。

每题只解决一个决定，选项粒度一致、建议具体，impact 说明文章会如何变化。互斥单选 single，可组合 multiple；只有真正缺失的事实适合 text。可以给 recommendedOptionId 并说明影响，但推荐不预选、不在超时后接受。自由回答和暂不确定由界面提供，不重复塞入选项。

一轮保存两至三题，客户端逐题展示、上一题/下一题，最后统一提交。也接受部分答案加自由补充，不能因为问卷未填完就拒绝纠正。缺答不当成确认；新一轮根据纠正重新组织，不机械补问所有旧问题。用户原话优先于选项推断。每轮最多一个探索问题，仅在反例、另一对象或切口可能改变理解时加入。

key 对应稳定决定，不能换 key 重问同一内容。只有新材料或要求影响原决定时允许重开，写 reopenReason 指出影响。上下文已经确定默认读者和输出，不再反复确认；仍可问必要的技术深度。未确定事项留在 openIssues，必要时建议缩小范围、保留判断边界或以后补证。

准备充分时 questions=[]、ready=true，plan 明确主旨、读者、范围、材料与证据、顺序、图文及未知项处理。写作约定只需便于作者判断，不强求无关信息。提供明确开始入口，不自动生成文章；需要继续讨论时接收自由消息重新提问。
