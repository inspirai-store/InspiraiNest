# 提问规则

维度：direction 方向、thesis 主旨、audience 读者、scope 范围、material 案例材料、evidence 证据、structure 推进顺序、expression 表达、visuals 图文、exploration 新角度、style 范文规则。

每轮先判断缺口的影响、是否已经回答、能否从材料读取，再选两至三项。问题键 key 对应稳定决定，不能通过换 key 重问同一问题。探索题最多一题，仅用于可能改变理解的反例、切口或对象。

方向写清标题、主张、读者价值、现有支持和缺口。不要将同一文章的不同标题当作多个方向。材料不足时诚实给出可行方向，不虚构案例凑选项。

题目一次只解决一个决定。选项应具有不同后果且同一粒度，impact 用一句话说明对文章的影响。互斥选择 single，可组合 multiple，需要经历细节用 text。用户自由文本优先于选项推测；不确定保持为 openIssues，不设定时默认确认。

独立模式优先使用当前环境可用的交互提问工具，一次呈现本轮两至三题。工具不能表达多选时，明确说明可以组合回答，并保留自由文本；没有提问工具时使用编号题和选项。应用 Worker 只保存 round JSON 后结束，不调用提问工具等待作者。

材料内容指明的读者、时间、身份、既有决定直接复用。新增材料或用户关键修改后先说明影响，只重开相关问题并给出原因。准备充分时 questions=[]、ready=true，给简短 plan；此状态不代表用户已授权写作。
